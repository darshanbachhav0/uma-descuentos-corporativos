# Referencias

El PDF original `FORMATO 1_FICHA DE EVALUACION SOCIOECONOMICA_2027-I.pdf` se copió sin modificar de la carpeta Descargas del usuario. El build publica una copia byte a byte para que el estudiante la descargue, la llene MANUALMENTE y la firme.

Los PDF `form 1.pdf`, `form 2.pdf` y `form 3.pdf` se revisaron localmente para confirmar escuelas, convenios y la estructura de cargas. Contienen contexto de una sesión de usuario y se excluyen de Git y de la publicación de Render.

El logotipo incluido en `src/assets/uma-logo.jpg` es la imagen incrustada en el PDF original, extraída sin rediseñarla. No se sustituyó la ficha por preguntas digitales ni se introdujeron respuestas en ella.
