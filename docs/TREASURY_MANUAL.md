# Manual de Tesorería

1. Abra la URL de Render e ingrese con el usuario y contraseña entregados. No hay acceso con Google.
2. Busque por nombre, documento, código o correo. Filtre por estado, convenio, escuela y fechas.
3. Abra **Revisar**. Compruebe datos, ficha firmada, sustentos y revisión de cada archivo. La vista previa y el botón Descargar funcionan dentro de la plataforma, sin iniciar sesión en Google.
4. Puede marcar **En revisión** o **Validada · pendiente SIGU**. Esos estados no generan el correo de aprobación.
5. Para aprobar, primero registre el descuento realmente en SIGU. Elija **COMPLETADO — APROBADO**, marque la confirmación, añada una referencia opcional y pulse **Guardar y notificar**. Revise el destinatario y confirme.
6. Para observar, elija **COMPLETADO — CON OBSERVACIÓN**, indique categoría, detalle y cómo subsanar. Confirme el mensaje. El expediente permanece OBSERVADA.
7. Al recibir una subsanación, el expediente pasa a CORRECCION_RECIBIDA. Revise los nuevos documentos y el historial antes de decidir nuevamente.
8. **Exportar Excel** crea una instantánea de los resultados filtrados con una hoja de solicitudes y otra de documentos. El archivo se descarga directamente. Sus enlaces abren el expediente o documento en el panel, con el mismo usuario y contraseña.

Los correos quedan en cola y el disparador del propietario los procesa aproximadamente cada minuto, sujeto a cuotas y disponibilidad de Google. **Aceptado por Google** significa que la llamada de envío fue aceptada, no que el estudiante abrió el mensaje.

Si un expediente cambió mientras lo revisaba, actualícelo antes de repetir la decisión. Los errores de documentos bloquean la aprobación hasta su recuperación. No cambie estados o destinatarios directamente en Sheets para intentar enviar notificaciones.

Gestión puede resolver un envío **Requiere comprobación**. Debe verificar con los registros disponibles y el destinatario si se envió. Puede confirmar el envío o reencolarlo dejando una explicación; reintentar un envío ya aceptado puede duplicarlo.

**Renovar enlace de subsanación** invalida el enlace anterior y encola uno nuevo. Úselo si venció o se requiere una nueva emisión mientras el expediente sigue observado.

Use **Cerrar sesión** al terminar. El usuario es compartido: todas las acciones se registran bajo ese nombre. Vea [QUICK_START.md](QUICK_START.md) para enlaces y ejemplo.
